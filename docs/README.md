# Promo video skill documentation

The promo video skill helps Claude turn your software product into short, narrated marketing videos. You answer a few questions, approve a storyboard, record a voiceover with ElevenLabs, and receive finished MP4 videos.

## Where to start

If you're new, read these pages in order:

1. [What the promo video skill does](overview.md): what you get and whether the skill fits your needs.
2. [Before you begin](prerequisites.md): the accounts, apps, and files you need.
3. [Set up the skill](getting-started.md): install the skill and check that your computer is ready.
4. [Quick start: make your first video](quick-start.md): the shortest path to your first finished video.
